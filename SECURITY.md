# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through [GitHub's vulnerability reporting form](https://github.com/bezel-labs/bezel-kit/security/advisories/new).

Include the affected package version, a minimal reproduction, and the expected impact. Remove any credentials or private project data.

## Scope

Bezel Kit processes design-token documents and provides a Node.js CLI. Reports involving crafted inputs, prototype pollution, excessive CPU or memory use, unsafe file access, or command execution are welcome.
